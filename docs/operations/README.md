# Operations Docs

Documentos operativos.

Esta carpeta se usara para runbooks de ejecucion local, dashboard, topologia de
despliegue, verificacion del worker y procedimientos de rollback.

Documentos principales:

- `deployment-topology.md`: como correr worker, admin API y dashboard.
- `runbook.md`: recuperacion, salud, reporte semanal y backup/restore.
- `evidence-policy.md`: lectura, retencion y sanitizacion de evidencia.
- `weekly-summary.md`: ultimo reporte operacional comparable.

El estado, validaciones cumplidas y definicion de terminado viven en
`../project-status.md`. Las tareas futuras viven solamente en `../roadmap/`.
