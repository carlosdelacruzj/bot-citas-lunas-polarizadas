# Reportes

Generadores de snapshots operativos, optimizacion, observaciones y evidencia.
Los artefactos se escriben en `reports/` y, por contrato histórico del generador,
en `docs/evidence-summary.md` y `docs/evidence-index.csv`.

Todo reporte debe declarar corte y cobertura. `latest` significa ultimo artefacto
escrito, no estado vivo. Las decisiones actuales deben refrescar PostgreSQL.

Politica: [`../../../docs/operations/evidence-policy.md`](../../../docs/operations/evidence-policy.md).
