# Reportes

Generadores de snapshots operativos, optimizacion, observaciones y evidencia.
Los artefactos se archivan por mes en `reports/`; el mes activo tambien se
publica en `docs/evidence-summary.md` y `docs/evidence-index.csv`.

Todo reporte debe declarar corte y cobertura. `latest` es un puntero o baseline
historica, no estado vivo. Las decisiones actuales deben refrescar PostgreSQL.

Politica: [`../../../docs/operations/evidence-policy.md`](../../../docs/operations/evidence-policy.md).
